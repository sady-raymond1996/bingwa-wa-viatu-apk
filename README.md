|---|---|
| **Customers** – Bingwa wa Viatu | [bingwa-wa-viatu.apk](https://github.com/sady-raymond1996/bingwa-wa-viatu-apk/releases/latest/download/bingwa-wa-viatu.apk) |

Older phones: if the normal file will not install, use the `-32bit.apk` version from the
[latest release](https://github.com/sady-raymond1996/bingwa-wa-viatu-apk/releases/latest).

**Install:** open the link on your Android phone → download → allow "install unknown apps" when asked → open the app → tap **Connect**.
The apps work on Wi-Fi or mobile data whenever the shop server is on.
